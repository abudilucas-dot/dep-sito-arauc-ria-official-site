# Depósito Araucária Official Site

Quero que você crie um site COMPLETO, FUNCIONAL, RESPONSIVO e PRONTO PARA PRODUÇÃO para a empresa:

DEPÓSITO ARAUCÁRIA
Instagram: https://www.instagram.com/depositoaraucaria/

IMPORTANTE:
As imagens de referência que estou fornecendo mostram a identidade visual REAL da empresa. Use essas referências como base principal do design.

NÃO quero um template genérico de loja.
Quero que o site pareça uma extensão oficial do Instagram e da identidade visual do Depósito Araucária.

1. IDENTIDADE VISUAL DA EMPRESA
==================================================

A marca utiliza principalmente:

- verde-limão / verde amarelado como cor principal;
- cinza grafite escuro;

- tons de cinza claro como apoio.

Visual da marca:
- moderno;
- industrial;
- ligado à construção civil;
- forte;
- profissional;
- limpo;
- confiável.

O Instagram utiliza bastante:

- fundos cinza escuro;

- linhas e curvas brancas;
- detalhes hexagonais;
- cards arredondados;
- imagens recortadas de produtos;
- profissionais da construção;
- ícones dentro de círculos verdes;
- títulos grandes e fortes;
- bastante contraste entre verde, branco e grafite.

Quero que o site siga ESSA MESMA DIREÇÃO.

NÃO use:
- azul como cor principal;
- gradientes coloridos aleatórios;
- visual de startup de tecnologia;
- aparência genérica de e-commerce;
- excesso de sombras;
- excesso de animações.
